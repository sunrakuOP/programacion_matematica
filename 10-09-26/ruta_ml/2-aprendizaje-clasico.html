2.1 Qué es "aprender": generalizar, no memorizar

Un modelo aprende cuando funciona bien con datos que nunca vio. Si solo funciona con los datos con que se entrenó, memorizó. Todo el aprendizaje automático clásico gira alrededor de esa diferencia. Tres ideas para tener claras:

  • Supervisado (hay respuesta correcta en los datos: regresión si es un número, clasificación si es una categoría), no supervisado (no hay respuesta: agrupar, comprimir) y por refuerzo (aprender de recompensas, 3.12).
  • Subajuste (underfitting): el modelo es tan simple que ni siquiera ajusta los datos de entrenamiento. Sobreajuste (overfitting): es tan flexible que ajusta hasta el ruido y falla con datos nuevos. Es el compromiso sesgo-varianza.
  • Tres conjuntos: entrenamiento (ajusta los parámetros), validación (elige el modelo e hiperparámetros) y prueba (se mira una sola vez, al final).

Un experimento que lo muestra con números. Datos: \(y = \sin(2\pi x)\) más ruido de desvío 0.2, 12 puntos de entrenamiento y 300 de prueba. Ajustamos polinomios de grado 1, 3 y 9 con las ecuaciones normales del tema 1.2:

sobreajuste.cppc++
#include <iostream>
#include <vector>
#include <random>
#include <cmath>
#include <utility>

using Matriz = std::vector<std::vector<double>>;
using Vector = std::vector<double>;

Vector resolver(Matriz A, Vector b) {                       // Gauss con pivoteo parcial
    int n = A.size();
    for (int c = 0; c < n; ++c) {
        int p = c;
        for (int f = c + 1; f < n; ++f) if (std::fabs(A[f][c]) > std::fabs(A[p][c])) p = f;
        std::swap(A[c], A[p]); std::swap(b[c], b[p]);
        for (int f = c + 1; f < n; ++f) {
            double m = A[f][c] / A[c][c];
            for (int k = c; k < n; ++k) A[f][k] -= m * A[c][k];
            b[f] -= m * b[c];
        }
    }
    Vector x(n);
    for (int i = n - 1; i >= 0; --i) {
        double s = b[i];
        for (int j = i + 1; j < n; ++j) s -= A[i][j] * x[j];
        x[i] = s / A[i][i];
    }
    return x;
}

// ajusta un polinomio de grado d con penalizacion ridge lambda:  (X^T X + lambda I) w = X^T y
Vector ajustar(const Vector& x, const Vector& y, int d, double lambda) {
    int m = d + 1, n = x.size();
    Matriz A(m, Vector(m, 0.0));
    Vector r(m, 0.0);
    for (int i = 0; i < n; ++i)
        for (int a = 0; a < m; ++a) {
            r[a] += std::pow(x[i], a) * y[i];
            for (int b = 0; b < m; ++b) A[a][b] += std::pow(x[i], a + b);
        }
    for (int a = 0; a < m; ++a) A[a][a] += lambda;
    return resolver(A, r);
}

double rmse(const Vector& w, const Vector& x, const Vector& y) {
    double s = 0;
    for (size_t i = 0; i < x.size(); ++i) {
        double p = 0;
        for (size_t a = 0; a < w.size(); ++a) p += w[a] * std::pow(x[i], a);
        s += (p - y[i]) * (p - y[i]);
    }
    return std::sqrt(s / x.size());
}

int main() {
    std::mt19937 gen(3);
    std::uniform_real_distribution<double> ux(0, 1);
    std::normal_distribution<double> ruido(0, 0.2);
    auto verdad = [](double x) { return std::sin(2 * M_PI * x); };

    Vector xt(12), yt(12), xs(300), ys(300);
    for (int i = 0; i < 12; ++i) { xt[i] = ux(gen); yt[i] = verdad(xt[i]) + ruido(gen); }
    for (int i = 0; i < 300; ++i) { xs[i] = ux(gen); ys[i] = verdad(xs[i]) + ruido(gen); }

    std::cout << "grado   error train   error test\n";
    for (int d : {1, 3, 9}) {
        Vector w = ajustar(xt, yt, d, 0.0);
        std::cout << "  " << d << "       " << rmse(w, xt, yt) << "         " << rmse(w, xs, ys) << "\n";
    }
    std::cout << "\ngrado 9 con ridge:\nlambda    error train   error test\n";
    for (double lam : {0.0, 1e-6, 1e-3, 1e-1}) {
        Vector w = ajustar(xt, yt, 9, lam);
        std::cout << lam << "      " << rmse(w, xt, yt) << "         " << rmse(w, xs, ys) << "\n";
    }
}

2.2 Regresión lineal: fórmula cerrada y descenso por gradiente

El mismo modelo se puede resolver de dos maneras, y es importante tener las dos: la fórmula cerrada (ecuaciones normales, tema 1.2) y el descenso por gradiente (1.6). La segunda es la que escala a modelos que no tienen fórmula cerrada, que son todos los interesantes (logística, redes).

La pérdida es el error cuadrático medio, \(L = \frac{1}{n}\sum_i (w x_i + b - y_i)^2\), y sus derivadas son \(\partial L/\partial w = \frac{2}{n}\sum e_i x_i\) y \(\partial L/\partial b = \frac{2}{n}\sum e_i\), con \(e_i\) el error de cada predicción. (El factor 2 se absorbe en la tasa de aprendizaje.)

regresion_gd.cppc++
#include <iostream>
#include <vector>
#include <random>

int main() {
    std::mt19937 gen(42);
    std::uniform_real_distribution<double> ux(0, 10);
    std::normal_distribution<double> ruido(0, 0.5);
    const int n = 200;
    std::vector<double> x(n), y(n);
    for (int i = 0; i < n; ++i) { x[i] = ux(gen); y[i] = 3.0 * x[i] + 2.0 + ruido(gen); }

    // (a) forma cerrada para y = w*x + b
    double sx = 0, sy = 0, sxx = 0, sxy = 0;
    for (int i = 0; i < n; ++i) { sx += x[i]; sy += y[i]; sxx += x[i] * x[i]; sxy += x[i] * y[i]; }
    double w = (n * sxy - sx * sy) / (n * sxx - sx * sx);
    double b = (sy - w * sx) / n;
    std::cout << "forma cerrada:     w = " << w << "  b = " << b << "\n";

    // (b) descenso por gradiente sobre el error cuadratico medio
    double wg = 0, bg = 0, lr = 0.01;
    for (int it = 1; it <= 20000; ++it) {
        double dw = 0, db = 0;
        for (int i = 0; i < n; ++i) {
            double e = wg * x[i] + bg - y[i];               // error de la prediccion
            dw += e * x[i];
            db += e;
        }
        wg -= lr * dw / n;
        bg -= lr * db / n;
        if (it == 100 || it == 1000 || it == 20000)
            std::cout << "descenso, iter " << it << ":  w = " << wg << "  b = " << bg << "\n";
    }
}

2.3 Regularización: ridge y lasso

La cura clásica del sobreajuste es penalizar los pesos grandes. Un polinomio de grado 9 que pasa por todo el ruido necesita coeficientes enormes que se compensan entre sí. Si se le pone un precio a los coeficientes grandes, el modelo prefiere curvas suaves.

Ridge minimiza \(\|Xw-y\|^2 + \lambda\|w\|^2\). Derivando, la solución son las mismas ecuaciones normales con un cambio mínimo: se suma \(\lambda\) a la diagonal, \((X^TX + \lambda I)\,w = X^Ty\). Es una sola línea en el programa de 2.1 (A[a][a] += lambda). Y de regalo mejora el condicionamiento de la matriz.

Salida real: grado 9 con ridge (mismo programa de 2.1, segunda tabla)
lambda    error train   error test
0      0.0928816         2.16634
1e-06      0.16318         0.345153
0.001      0.234362         0.223597
0.1      0.432124         0.402893
  • \(\lambda = 0\) (sin regularizar): train 0.09, test 2.17. Sobreajuste total.
  • \(\lambda = 10^{-3}\): train 0.23, test 0.22. El de entrenamiento sube (ya no memoriza) y el de prueba baja diez veces. Es el punto dulce.
  • \(\lambda = 0.1\): train 0.43, test 0.40. Ahora el modelo está demasiado rígido: subajuste. Un \(\lambda\) demasiado grande lo aplana.

Lasso usa \(\lambda\|w\|_1\) (suma de valores absolutos) en vez de la suma de cuadrados. Tiene una propiedad útil: lleva varios coeficientes exactamente a cero, o sea que selecciona características. No tiene fórmula cerrada y se resuelve con descenso por coordenadas o subgradiente.

OjoMi programa penaliza todos los coeficientes, incluida la ordenada \(w_0\). Es una simplificación; en la práctica no se penaliza el término constante. Tenelo en cuenta cuando lo hagas vos.

2.4 Regresión logística y clasificación

Para predecir una categoría (sí/no) se pasa el resultado lineal \(z = w\cdot x + b\) por la sigmoide \(\sigma(z) = 1/(1+e^{-z})\), que lo convierte en una probabilidad entre 0 y 1. La pérdida natural es la entropía cruzada y, sorpresa agradable, su gradiente tiene la misma forma que el de la regresión lineal: \(\partial L/\partial w = \frac{1}{n}\sum (\sigma(z_i) - y_i)\,x_i\). Por eso el código es casi idéntico al de 2.2.

logistica.cppc++
#include <iostream>
#include <vector>
#include <random>
#include <cmath>

struct Punto { double x, y; int clase; };

int main() {
    std::mt19937 gen(5);
    std::normal_distribution<double> r(0, 1.0);
    auto datos = [&](int n) {
        std::vector<Punto> v;
        for (int i = 0; i < n; ++i) { int c = i % 2; double mu = c ? 1.2 : -1.2; v.push_back({mu + r(gen), mu + r(gen), c}); }
        return v;
    };
    auto train = datos(400), test = datos(400);

    double w1 = 0, w2 = 0, b = 0, lr = 0.1;
    auto sigmoide = [](double z) { return 1.0 / (1.0 + std::exp(-z)); };
    for (int it = 0; it < 2000; ++it) {
        double g1 = 0, g2 = 0, gb = 0;
        for (const auto& p : train) {
            double e = sigmoide(w1 * p.x + w2 * p.y + b) - p.clase;   // (prediccion - real)
            g1 += e * p.x; g2 += e * p.y; gb += e;
        }
        int n = train.size();
        w1 -= lr * g1 / n; w2 -= lr * g2 / n; b -= lr * gb / n;
    }

    int tp = 0, fp = 0, fn = 0, tn = 0;
    for (const auto& p : test) {
        int pred = sigmoide(w1 * p.x + w2 * p.y + b) > 0.5;
        if (pred && p.clase) ++tp; else if (pred && !p.clase) ++fp; else if (!pred && p.clase) ++fn; else ++tn;
    }
    double prec = double(tp) / (tp + fp), rec = double(tp) / (tp + fn);
    std::cout << "w = (" << w1 << ", " << w2 << ")  b = " << b << "\n";
    std::cout << "matriz de confusion (test):  TP=" << tp << " FP=" << fp << " FN=" << fn << " TN=" << tn << "\n";
    std::cout << "exactitud = " << double(tp + tn) / test.size() << "  precision = " << prec << "  recall = " << rec
              << "  F1 = " << 2 * prec * rec / (prec + rec) << "\n";
}

Los datos son dos nubes gaussianas que se solapan un poco (centradas en (−1.2, −1.2) y (1.2, 1.2)). Con 400 ejemplos de prueba:

predijo 1predijo 0
realmente 1TP = 192FN = 8
realmente 0FP = 4TN = 196
  • Exactitud (accuracy) = (TP+TN)/total = 388/400 = 0.97.
  • Precisión = TP/(TP+FP): de los que dije "1", cuántos eran 1. Recall = TP/(TP+FN): de los que eran 1, cuántos encontré. F1 es su media armónica.
  • La exactitud engaña con clases desbalanceadas: si solo el 1% son positivos, un modelo que siempre dice "no" tiene 99% de exactitud y es inútil. Mirá siempre precisión y recall.

2.5 k vecinos más cercanos (k-NN) y búsqueda espacial

El algoritmo más simple que existe: para clasificar un punto nuevo, buscá los \(k\) ejemplos de entrenamiento más cercanos y votá. No hay entrenamiento: el modelo es el conjunto de datos. Funciona cuando una frontera recta no alcanza, como en este problema (una clase en un disco central, la otra en un anillo alrededor):

datos2d.hppc++
#pragma once
#include <vector>
#include <random>
#include <cmath>
struct Punto { double x, y; int clase; };
// clase 0: disco de radio ~1.5 en el centro; clase 1: anillo de radio 2.5 a 4
inline std::vector<Punto> anillo(int n, unsigned semilla) {
    std::mt19937 g(semilla);
    std::uniform_real_distribution<double> ang(0, 2 * M_PI), r0(0, 1.5), r1(2.5, 4.0);
    std::vector<Punto> v;
    for (int i = 0; i < n; ++i) {
        double a = ang(g);
        int c = i % 2;
        double r = c == 0 ? r0(g) : r1(g);
        v.push_back({r * std::cos(a), r * std::sin(a), c});
    }
    return v;
}
knn_vs_logistica.cppc++
#include <iostream>
#include <vector>
#include <algorithm>
#include <cmath>
#include "datos2d.hpp"

int main() {
    auto train = anillo(400, 1), test = anillo(400, 2);

    // --- regresion logistica (frontera RECTA)
    double w1 = 0, w2 = 0, b = 0;
    auto sig = [](double z) { return 1.0 / (1.0 + std::exp(-z)); };
    for (int it = 0; it < 3000; ++it) {
        double g1 = 0, g2 = 0, gb = 0;
        for (auto& p : train) { double e = sig(w1 * p.x + w2 * p.y + b) - p.clase; g1 += e * p.x; g2 += e * p.y; gb += e; }
        w1 -= 0.1 * g1 / train.size(); w2 -= 0.1 * g2 / train.size(); b -= 0.1 * gb / train.size();
    }
    int okLog = 0;
    for (auto& p : test) okLog += (sig(w1 * p.x + w2 * p.y + b) > 0.5) == p.clase;

    // --- k-NN por fuerza bruta: O(n) por consulta
    auto knn = [&](const Punto& q, int k) {
        std::vector<std::pair<double, int>> d;
        for (auto& p : train) d.push_back({(p.x - q.x) * (p.x - q.x) + (p.y - q.y) * (p.y - q.y), p.clase});
        std::partial_sort(d.begin(), d.begin() + k, d.end());
        int votos = 0;
        for (int i = 0; i < k; ++i) votos += d[i].second;
        return votos * 2 > k ? 1 : 0;
    };
    std::cout << "regresion logistica: exactitud = " << double(okLog) / test.size() << "\n";
    for (int k : {1, 5, 15, 51}) {
        int ok = 0;
        for (auto& p : test) ok += knn(p, k) == p.clase;
        std::cout << "k-NN con k = " << k << ":  exactitud = " << double(ok) / test.size() << "\n";
    }
}

regresion logistica: exactitud = 0.5725

  • La regresión logística llega a 0.5725, apenas mejor que tirar una moneda: ninguna recta separa un disco de un anillo.
  • k-NN saca 1.0 para todos los \(k\) probados. Ojo: esto es porque mis datos están perfectamente separados (hay un hueco entre el disco y el anillo). Con datos reales con ruido, un \(k\) chico sobreajusta (sigue el ruido) y uno grande suaviza demasiado: hay que elegirlo con validación (2.12).

El costo: cada consulta recorre todos los \(n\) ejemplos, \(O(nd)\). Con millones de ejemplos es lento. Acá entran tus árboles: un kd-tree (el quad-tree del tema 2.4 de la Ruta de Código, generalizado a \(d\) dimensiones) busca el vecino más cercano en \(O(\log n)\) en promedio cuando \(d\) es chica. Cuando \(d\) crece (decenas de dimensiones) la ventaja se pierde: es la maldición de la dimensionalidad.

2.6 Árboles de decisión (CART)

Un árbol de decisión es exactamente lo que ya estudiás: un árbol binario construido por recursión. Cada nodo interno hace una pregunta sobre una característica ("¿x ≤ 1.7?") y manda el ejemplo a la izquierda o a la derecha; las hojas dan la clase. La pregunta se elige para que los dos hijos queden lo más "puros" posible.

La impureza se mide con el índice de Gini: \(G = 1 - \sum_k p_k^2\), donde \(p_k\) es la proporción de la clase \(k\) en el nodo. Un nodo puro vale 0; uno mitad y mitad (con 2 clases) vale 0.5. Se prueba cada característica y cada umbral y se elige el que minimice el Gini medio de los hijos.

arbol_cart.cppc++
#include <iostream>
#include <vector>
#include <memory>
#include <algorithm>
#include <cmath>
#include "datos2d.hpp"

struct Nodo {
    int campo = -1;            // 0 = x, 1 = y ; -1 = hoja
    double umbral = 0;
    int clase = 0;
    std::unique_ptr<Nodo> izq, der;
};

double gini(int n0, int n1) {                               // 1 - sum p^2
    double n = n0 + n1;
    if (n == 0) return 0;
    double p0 = n0 / n, p1 = n1 / n;
    return 1 - p0 * p0 - p1 * p1;
}
double valor(const Punto& p, int campo) { return campo == 0 ? p.x : p.y; }

std::unique_ptr<Nodo> construir(const std::vector<Punto>& d, int prof, int maxProf) {
    auto nodo = std::make_unique<Nodo>();
    int c1 = 0;
    for (auto& p : d) c1 += p.clase;
    int c0 = d.size() - c1;
    nodo->clase = c1 > c0;
    if (prof == maxProf || c0 == 0 || c1 == 0 || d.size() < 2) return nodo;

    double mejor = gini(c0, c1), mejorUmbral = 0; int mejorCampo = -1;
    for (int campo = 0; campo < 2; ++campo)
        for (auto& cand : d) {                              // cada valor es un umbral candidato
            double u = valor(cand, campo);
            int l0 = 0, l1 = 0, r0 = 0, r1 = 0;
            for (auto& p : d) { bool izq = valor(p, campo) <= u; (izq ? (p.clase ? l1 : l0) : (p.clase ? r1 : r0))++; }
            if (l0 + l1 == 0 || r0 + r1 == 0) continue;
            double g = (gini(l0, l1) * (l0 + l1) + gini(r0, r1) * (r0 + r1)) / d.size();
            if (g < mejor - 1e-12) { mejor = g; mejorUmbral = u; mejorCampo = campo; }
        }
    if (mejorCampo < 0) return nodo;

    std::vector<Punto> izq, der;
    for (auto& p : d) (valor(p, mejorCampo) <= mejorUmbral ? izq : der).push_back(p);
    nodo->campo = mejorCampo; nodo->umbral = mejorUmbral;
    nodo->izq = construir(izq, prof + 1, maxProf);          // recursion: el mismo problema, mas chico
    nodo->der = construir(der, prof + 1, maxProf);
    return nodo;
}
int predecir(const Nodo* n, const Punto& p) {
    while (n->campo >= 0) n = valor(p, n->campo) <= n->umbral ? n->izq.get() : n->der.get();
    return n->clase;
}

int main() {
    auto train = anillo(400, 1), test = anillo(400, 2);
    std::cout << "profundidad   exactitud train   exactitud test\n";
    for (int prof : {1, 2, 3, 5, 8, 20}) {
        auto raiz = construir(train, 0, prof);
        int okT = 0, okS = 0;
        for (auto& p : train) okT += predecir(raiz.get(), p) == p.clase;
        for (auto& p : test) okS += predecir(raiz.get(), p) == p.clase;
        std::cout << "    " << prof << "              " << double(okT) / train.size() << "             " << double(okS) / test.size() << "\n";
    }
}

2.7 Bagging y bosques aleatorios (random forest)

Un árbol profundo tiene poco sesgo pero mucha varianza: cambia mucho si cambian un poco los datos. La idea de bagging: entrenar muchos árboles, cada uno con una muestra con reemplazo de los datos (bootstrap), y promediar o votar. Los errores de cada uno se compensan y la varianza baja.

El random forest agrega un truco: en cada corte, cada árbol solo considera un subconjunto al azar de las características. Eso hace que los árboles sean distintos entre sí (decorrelacionados), y promediar árboles distintos reduce más la varianza que promediar copias parecidas.

  • Bootstrap: una muestra de tamaño \(n\) con reemplazo deja afuera cerca del 36.8% de los ejemplos (\((1-1/n)^n \to e^{-1}\)). Esos ejemplos "fuera de la bolsa" sirven como validación gratuita: el error OOB (out-of-bag).
  • Importancia de características: cuánto baja la impureza (o sube el error al barajar esa columna) en promedio entre los árboles.

2.8 Boosting: corregir los errores del anterior

Si el bagging reduce la varianza promediando árboles independientes, el boosting reduce el sesgo construyendo árboles en secuencia: cada uno corrige los errores del conjunto anterior. En gradient boosting para regresión es casi un descenso por gradiente en el espacio de funciones: el siguiente árbol se ajusta a los residuos (\(y\) menos la predicción actual) y se suma con un factor chico (la tasa de aprendizaje).

Con árboles muy chicos (de profundidad 1, stumps) y cientos de rondas se llega a modelos muy potentes. Las implementaciones de producción más usadas (XGBoost, LightGBM, CatBoost) son este mismo algoritmo con muchísima ingeniería; las vas a encontrar en Python (tema 4.4).

2.9 SVM y el truco del kernel (panorama)

Una máquina de vectores de soporte busca, entre todas las rectas (o hiperplanos) que separan las clases, la que deja el mayor margen a ambos lados. Los pocos ejemplos que tocan el margen son los vectores de soporte, y son los únicos que definen el modelo. La pérdida es la bisagra (hinge): \(\max(0,\ 1 - y\,(w\cdot x + b))\) con \(y \in \{-1, +1\}\).

El truco del kernel: si los datos no son separables con una recta (como el anillo de 2.5), se calculan productos punto como si estuvieran en un espacio de más dimensiones, sin construirlo. Con el kernel gaussiano (RBF) se obtienen fronteras curvas.

2.10 k-means: agrupar sin respuestas

Sin etiquetas, el problema es encontrar estructura. k-means parte los datos en \(k\) grupos con el algoritmo de Lloyd: (1) asignar cada punto al centroide más cercano; (2) mover cada centroide al promedio de sus puntos; repetir hasta que no cambie nada. Cada vuelta baja (o mantiene) la inercia, la suma de distancias al cuadrado a su centroide, así que siempre converge, aunque a un mínimo local.

kmeans.cppc++
#include <iostream>
#include <vector>
#include <random>
#include <cmath>
#include <algorithm>

struct P { double x, y; };

int main() {
    std::mt19937 gen(11);
    std::normal_distribution<double> r(0, 0.8);
    P centros[3] = {{0, 0}, {6, 0}, {3, 5}};
    std::vector<P> datos;
    for (auto& c : centros) for (int i = 0; i < 100; ++i) datos.push_back({c.x + r(gen), c.y + r(gen)});

    const int K = 3;
    std::vector<P> mu = {datos[0], datos[150], datos[250]};   // inicializacion simple: 3 puntos cualquiera
    std::vector<int> asign(datos.size(), -1);
    for (int iter = 1; iter <= 100; ++iter) {
        bool cambio = false;
        for (size_t i = 0; i < datos.size(); ++i) {           // 1) asignar al centroide mas cercano
            int mejor = 0; double dm = 1e18;
            for (int k = 0; k < K; ++k) {
                double d = std::pow(datos[i].x - mu[k].x, 2) + std::pow(datos[i].y - mu[k].y, 2);
                if (d < dm) { dm = d; mejor = k; }
            }
            if (asign[i] != mejor) { asign[i] = mejor; cambio = true; }
        }
        P suma[K] = {}; int cuenta[K] = {};
        for (size_t i = 0; i < datos.size(); ++i) { suma[asign[i]].x += datos[i].x; suma[asign[i]].y += datos[i].y; ++cuenta[asign[i]]; }
        for (int k = 0; k < K; ++k) if (cuenta[k]) mu[k] = {suma[k].x / cuenta[k], suma[k].y / cuenta[k]};   // 2) mover
        if (!cambio) {
            double inercia = 0;
            for (size_t i = 0; i < datos.size(); ++i) inercia += std::pow(datos[i].x - mu[asign[i]].x, 2) + std::pow(datos[i].y - mu[asign[i]].y, 2);
            std::sort(mu.begin(), mu.end(), [](const P& a, const P& b) { return a.x < b.x; });
            std::cout << "convergio en " << iter << " iteraciones, inercia = " << inercia << "\n";
            for (auto& m : mu) std::cout << "centroide (" << m.x << ", " << m.y << ")\n";
            break;
        }
    }
}

2.11 PCA: comprimir quedándose con lo que varía

Si los datos tienen muchas características correlacionadas, la mayor parte de la información está en pocas direcciones. PCA (análisis de componentes principales) encuentra esas direcciones: son los autovectores de la matriz de covarianza, ordenados por autovalor. La primera componente es la dirección de mayor varianza; el cociente \(\lambda_1/\sum\lambda\) es la fracción de la varianza que explica.

Y ya tenés la herramienta: el método de la potencia de Chapra (tema 3.4 de la Ruta de Código) calcula justamente el autovector dominante:

pca_potencia.cppc++
#include <iostream>
#include <vector>
#include <random>
#include <cmath>

int main() {
    std::mt19937 gen(8);
    std::normal_distribution<double> a(0, 3.0), b(0, 0.5);
    const int n = 1000;
    std::vector<double> X(n), Y(n);
    for (int i = 0; i < n; ++i) { double t = a(gen); X[i] = t + b(gen); Y[i] = 0.5 * t + b(gen); }   // datos alargados en una direccion

    double mx = 0, my = 0;
    for (int i = 0; i < n; ++i) { mx += X[i] / n; my += Y[i] / n; }
    double cxx = 0, cxy = 0, cyy = 0;                       // matriz de covarianza 2x2
    for (int i = 0; i < n; ++i) { cxx += (X[i] - mx) * (X[i] - mx); cxy += (X[i] - mx) * (Y[i] - my); cyy += (Y[i] - my) * (Y[i] - my); }
    cxx /= n - 1; cxy /= n - 1; cyy /= n - 1;

    double v[2] = {1, 0}, lambda = 0;                       // metodo de la potencia (el de Chapra, tema 3.4)
    for (int it = 0; it < 100; ++it) {
        double w0 = cxx * v[0] + cxy * v[1], w1 = cxy * v[0] + cyy * v[1];
        lambda = std::sqrt(w0 * w0 + w1 * w1);
        v[0] = w0 / lambda; v[1] = w1 / lambda;
    }
    double traza = cxx + cyy, lambda2 = traza - lambda;     // la traza es la suma de los autovalores
    std::cout << "covarianza: [" << cxx << " " << cxy << "; " << cxy << " " << cyy << "]\n";
    std::cout << "autovalor 1 = " << lambda << "  direccion = (" << v[0] << ", " << v[1] << ")\n";
    std::cout << "autovalor 2 = " << lambda2 << "\n";
    std::cout << "varianza explicada por la 1ra componente = " << lambda / traza << "\n";
}
Salida real
covarianza: [9.0552 4.5188; 4.5188 2.56424]
autovalor 1 = 11.3732  direccion = (0.889761, 0.456426)
autovalor 2 = 0.246206
varianza explicada por la 1ra componente = 0.978811

Los datos son una nube alargada: casi todo el movimiento está sobre una dirección, la de (0.89, 0.46), y la primera componente explica 97.9% de la varianza. Si proyectás cada punto sobre esa recta (de 2 números a 1) perdés apenas el 2%.

LímiteLa traza de la matriz (suma de la diagonal) es la suma de los autovalores; por eso saqué el segundo como traza − λ₁. Eso solo sirve en 2×2. Para más dimensiones necesitás todos los pares autovalor-autovector (deflación, o el algoritmo QR / SVD; Eigen los trae, 4.6).

2.12 Validación y selección de modelos

¿Cómo sabés si tu modelo sirve? Con una sola partición train/test el número depende de la suerte de esa partición. La validación cruzada de \(k\) pliegues (k-fold) divide los datos en \(k\) partes, entrena \(k\) veces dejando una parte afuera cada vez, y promedia: da una estimación más estable y su desvío.

Con ella se eligen los hiperparámetros (\(\lambda\) de ridge, \(k\) de k-NN, profundidad del árbol) y se compara entre modelos. Reglas que evitan los errores más comunes:

  • Un baseline primero: predecir siempre la media (regresión) o la clase más frecuente (clasificación). Si tu modelo no le gana, no aprendió nada.
  • Todo el preprocesamiento va dentro de cada pliegue (la media y el desvío de 1.4 se calculan con los datos de entrenamiento de ese pliegue). Si estandarizás antes de dividir, hay fuga de datos.
  • El conjunto de prueba se toca una vez. Si lo usás para decidir, deja de ser de prueba.
  • Métricas: regresión (RMSE, MAE, \(R^2\)); clasificación (exactitud, precisión, recall, F1, área bajo la curva ROC).

2.13 Modelos probabilísticos: Naive Bayes y mezclas gaussianas (panorama)

Hasta acá los modelos predicen directamente. Los probabilísticos modelan cómo se generaron los datos y usan la regla de Bayes para clasificar. Naive Bayes supone que las características son independientes dado la clase (lo cual casi nunca es cierto, y aun así anda sorprendentemente bien), así que el modelo se reduce a contar: cuántas veces aparece cada palabra en cada clase. Es el clasificador de spam clásico, y se implementa con un unordered_map<string,int> por clase.

Una mezcla gaussiana (GMM) es un k-means "suave": cada punto pertenece a cada grupo con cierta probabilidad. Se ajusta con el algoritmo EM (esperanza-maximización), que alterna estimar las pertenencias y re-estimar las gaussianas; en k-means esas pertenencias eran 0 o 1.
