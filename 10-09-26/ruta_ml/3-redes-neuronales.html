3.1 La neurona, las capas y la red (MLP)

Una neurona hace lo que ya hacés en la regresión logística (2.4): calcula \(z = w\cdot x + b\) y le aplica una función no lineal, la activación, \(a = f(z)\). Una capa es un montón de neuronas en paralelo, o sea una matriz: \(a = f(Wx + b)\), con \(W\) de tamaño (neuronas × entradas). Un MLP (perceptrón multicapa) apila capas: la salida de una es la entrada de la siguiente.

La no linealidad es lo que hace que la red sirva. Sin ella, dos capas lineales se reducen a una sola (\(W_2(W_1x) = (W_2W_1)x\)) y la red no podría resolver ni un XOR.

ActivaciónFórmulaRangoPara qué
sigmoide\(1/(1+e^{-z})\)(0, 1)salida de probabilidad; en capas ocultas tiende a saturar (3.7)
tanh\((e^z - e^{-z})/(e^z + e^{-z})\)(−1, 1)centrada en 0; la que usa el XOR de 3.4
ReLU\(\max(0, z)\)[0, ∞)la más usada en capas ocultas: barata y no satura para \(z>0\)

Contar parámetros es un hábito útil: una capa de \(m\) entradas y \(k\) neuronas tiene \(mk + k\) parámetros (pesos más sesgos). Una red 784-128-10 (imágenes de 28×28 clasificadas en 10 clases) tiene \((784\cdot128 + 128) + (128\cdot10 + 10) = 101{.}770\).

3.2 Funciones de pérdida y la capa de salida

La pérdida le dice a la red cuánto se equivoca; todo el entrenamiento es bajarla. Según el problema:

ProblemaSalidaPérdida
regresiónun número (sin activación)error cuadrático medio \(\frac1n\sum(\hat y - y)^2\)
2 clasessigmoideentropía cruzada binaria \(-[y\ln\hat y + (1-y)\ln(1-\hat y)]\)
\(K\) clasessoftmaxentropía cruzada \(-\ln \hat y_{\text{clase correcta}}\)

El softmax convierte \(K\) números cualquiera en \(K\) probabilidades que suman 1: \(\text{softmax}(z)_i = e^{z_i}/\sum_j e^{z_j}\). Ejemplo con \(z = (2, 1, 0)\): las exponenciales son 7.389, 2.718 y 1; suman 11.107; el resultado es \((0.665,\ 0.245,\ 0.090)\). Si la clase correcta es la primera, la pérdida es \(-\ln 0.665 = 0.408\).

Estabilidad numéricaCon \(z\) grandes (por ejemplo 1000) \(e^{z}\) desborda a infinito. La versión estable resta el máximo antes de exponenciar (\(e^{z_i - \max z}\)), que da el mismo resultado. Y \(\ln(0)\) es \(-\infty\): hay que acotar las probabilidades (por ejemplo, a \(10^{-12}\)) antes de aplicar el logaritmo.

3.3 Backpropagation: derivar el entrenamiento a mano

Entrenar una red es aplicar el descenso por gradiente (1.6) a todos sus pesos. El problema es calcular el gradiente de la pérdida respecto de cada peso. Backpropagation no es un algoritmo misterioso: es la regla de la cadena aplicada de la salida hacia la entrada, reutilizando cálculos intermedios.

Tomá la red del XOR de 3.4: una capa oculta de tanh y una salida sigmoide con entropía cruzada. Hacia adelante:

  • \(z_1 = W_1 x + b_1\) → \(h = \tanh(z_1)\) → \(z_2 = w_2\cdot h + b_2\) → \(\hat y = \sigma(z_2)\) → \(L = -[y\ln\hat y + (1-y)\ln(1-\hat y)]\)

Hacia atrás se va derivando paso por paso, y cada derivada reutiliza la del paso siguiente:

  • \(\delta_2 = \partial L/\partial z_2 = \hat y - y\) (la simplificación elegante de sigmoide + entropía cruzada)
  • \(\partial L/\partial w_2 = \delta_2\, h\) y \(\partial L/\partial b_2 = \delta_2\)
  • \(\partial L/\partial h = \delta_2\, w_2\) y luego \(\delta_1 = \partial L/\partial z_1 = (\delta_2\, w_2) \odot (1 - h^2)\) (la derivada de tanh es \(1 - \tanh^2\))
  • \(\partial L/\partial W_1 = \delta_1\, x^T\) y \(\partial L/\partial b_1 = \delta_1\)

La regla práctica para no equivocarte con las dimensiones: el gradiente de una matriz tiene siempre el mismo tamaño que la matriz (\(\partial L/\partial W_1\) es 4×2 si \(W_1\) es 4×2). Si te da otro tamaño, hay una transpuesta mal.

3.4 Un MLP desde cero en C++: el XOR

El XOR (1 si las dos entradas son distintas) es el ejemplo histórico: ninguna recta separa {(0,0), (1,1)} de {(0,1), (1,0)}, así que la regresión logística no puede. Una capa oculta sí. El programa que sigue entrena una red 2-4-1 con las fórmulas de 3.3, sin ninguna librería:

mlp_xor.cppc++
#include <iostream>
#include <vector>
#include <random>
#include <cmath>

const int H = 4;                                            // neuronas ocultas

int main() {
    std::mt19937 gen(1);
    std::normal_distribution<double> init(0, 0.8);
    double W1[H][2], b1[H], W2[H], b2 = 0;                  // capa 1: 2 -> H (tanh), capa 2: H -> 1 (sigmoide)
    for (int j = 0; j < H; ++j) { W1[j][0] = init(gen); W1[j][1] = init(gen); b1[j] = 0; W2[j] = init(gen); }

    double X[4][2] = {{0, 0}, {0, 1}, {1, 0}, {1, 1}};
    double T[4] = {0, 1, 1, 0};                             // XOR: ninguna recta lo separa
    auto sig = [](double z) { return 1.0 / (1.0 + std::exp(-z)); };
    double lr = 0.5;

    for (int epoca = 0; epoca <= 5000; ++epoca) {
        double perdida = 0, dW1[H][2] = {}, db1[H] = {}, dW2[H] = {}, db2 = 0;
        for (int n = 0; n < 4; ++n) {
            double h[H], z2 = b2;                           // ---- hacia adelante
            for (int j = 0; j < H; ++j) {
                h[j] = std::tanh(W1[j][0] * X[n][0] + W1[j][1] * X[n][1] + b1[j]);
                z2 += W2[j] * h[j];
            }
            double y = sig(z2);
            perdida += -(T[n] * std::log(y) + (1 - T[n]) * std::log(1 - y));
            double dz2 = y - T[n];                          // ---- hacia atras (regla de la cadena)
            db2 += dz2;
            for (int j = 0; j < H; ++j) {
                dW2[j] += dz2 * h[j];
                double dz1 = dz2 * W2[j] * (1 - h[j] * h[j]);      // d tanh = 1 - tanh^2
                dW1[j][0] += dz1 * X[n][0]; dW1[j][1] += dz1 * X[n][1]; db1[j] += dz1;
            }
        }
        for (int j = 0; j < H; ++j) { W2[j] -= lr * dW2[j] / 4; b1[j] -= lr * db1[j] / 4; W1[j][0] -= lr * dW1[j][0] / 4; W1[j][1] -= lr * dW1[j][1] / 4; }
        b2 -= lr * db2 / 4;
        if (epoca % 1000 == 0) std::cout << "epoca " << epoca << "   perdida = " << perdida / 4 << "\n";
    }
    for (int n = 0; n < 4; ++n) {
        double z2 = b2;
        for (int j = 0; j < H; ++j) z2 += W2[j] * std::tanh(W1[j][0] * X[n][0] + W1[j][1] * X[n][1] + b1[j]);
        std::cout << X[n][0] << " XOR " << X[n][1] << " -> " << sig(z2) << "   (esperado " << T[n] << ")\n";
    }
}

3.5 Derivación automática: el grafo de cómputo (micrograd en C++)

Derivar a mano cada red nueva es inviable. La solución, que está debajo de PyTorch y TensorFlow, es la derivación automática (autodiff): cada operación (+, ×, tanh…) registra cómo se deriva ella sola, y el sistema encadena esas reglas locales con la regla de la cadena. Se hace en dos pasadas: hacia adelante se calcula el valor y se arma un grafo dirigido sin ciclos; hacia atrás se recorre ese grafo en orden topológico inverso acumulando gradientes.

Y acá se juntan dos cosas que ya estudiaste: cada nodo guarda su regla de derivada en una lambda (std::function) y el recorrido hacia atrás es un orden topológico (tema 2.9 de la Ruta de Código). Este es el esquema de micrograd de Karpathy, traducido a C++:

autodiff.cppc++
#include <iostream>
#include <vector>
#include <memory>
#include <functional>
#include <unordered_set>
#include <cmath>

struct Nodo;
using V = std::shared_ptr<Nodo>;

struct Nodo {
    double dato, grad = 0;
    std::vector<V> hijos;                                   // de quien depende este valor
    std::function<void()> retroceder = [] {};               // la regla de la cadena de ESTA operacion
    explicit Nodo(double d) : dato(d) {}
};
V valor(double d) { return std::make_shared<Nodo>(d); }

V operator+(V a, V b) {
    V o = valor(a->dato + b->dato);
    o->hijos = {a, b};
    Nodo* p = o.get();
    o->retroceder = [a, b, p] { a->grad += p->grad; b->grad += p->grad; };
    return o;
}
V operator*(V a, V b) {
    V o = valor(a->dato * b->dato);
    o->hijos = {a, b};
    Nodo* p = o.get();
    o->retroceder = [a, b, p] { a->grad += b->dato * p->grad; b->grad += a->dato * p->grad; };
    return o;
}
V tanh(V a) {
    V o = valor(std::tanh(a->dato));
    o->hijos = {a};
    Nodo* p = o.get();
    o->retroceder = [a, p] { a->grad += (1 - p->dato * p->dato) * p->grad; };
    return o;
}

void backward(V salida) {
    std::vector<Nodo*> orden;                               // orden topologico (DFS)
    std::unordered_set<Nodo*> visto;
    std::function<void(Nodo*)> visitar = [&](Nodo* n) {
        if (!visto.insert(n).second) return;
        for (auto& h : n->hijos) visitar(h.get());
        orden.push_back(n);
    };
    visitar(salida.get());
    salida->grad = 1;
    for (auto it = orden.rbegin(); it != orden.rend(); ++it) (*it)->retroceder();
}

int main() {
    V a = valor(2.0), b = valor(-3.0), c = valor(10.0);
    V f = tanh(a * b + c);                                  // f = tanh(a*b + c)
    backward(f);
    double z = 2.0 * -3.0 + 10.0, d = 1 - std::tanh(z) * std::tanh(z);   // derivada a mano
    std::cout << "f = " << f->dato << "\n";
    std::cout << "df/da = " << a->grad << "   (a mano: " << d * -3.0 << ")\n";
    std::cout << "df/db = " << b->grad << "   (a mano: " << d * 2.0 << ")\n";
    std::cout << "df/dc = " << c->grad << "   (a mano: " << d << ")\n";
}
Salida real

  • El programa deriva \(f = \tanh(ab + c)\) con \(a=2,\ b=-3,\ c=10\). Los tres gradientes coinciden hasta el último dígito con los calculados a mano (\(\partial f/\partial a = (1-\tanh^2 z)\cdot b\), etc.).
  • grad += y no grad =: una variable puede usarse varias veces (por ejemplo \(f = a\cdot a\)) y cada uso aporta su parte al gradiente; hay que sumarlas.
  • Detalle de memoria: la lambda de cada nodo captura a sus hijos con shared_ptr pero a sí mismo con un puntero crudo p. Si capturara su propio shared_ptr, el nodo se apuntaría a sí mismo a través de su lambda: un ciclo de referencias, y la memoria nunca se liberaría.

3.6 Optimizadores: SGD, momentum y Adam

El descenso por gradiente (1.6) se puede mejorar. Tres variantes, de menor a mayor sofisticación:

  • SGD / mini-lotes: en vez de usar los \(n\) datos para cada paso, usar un lote de, digamos, 32. Es mucho más barato por paso y el ruido ayuda a salir de zonas planas.
  • Momentum: acumular una "velocidad" \(v \leftarrow \beta v + g\) y moverse con ella. En un valle largo y angosto amortigua las oscilaciones de los costados y acelera a lo largo.
  • Adam: momentum más una tasa de aprendizaje propia para cada parámetro, escalada por el historial del tamaño de sus gradientes. Es el optimizador por defecto de la mayoría de las redes.

Los comparé sobre el valle \(f(x,y) = x^2 + 10y^2\), partiendo de (5, 5) hasta llegar a \(f<10^{-8}\):

optimizadores.cppc++
#include <iostream>
#include <cmath>
#include <string>

// f(x, y) = x^2 + 10 y^2   (un "valle" alargado: lo que mas cuesta a un gradiente simple)
void gradiente(double x, double y, double& gx, double& gy) { gx = 2 * x; gy = 20 * y; }
double f(double x, double y) { return x * x + 10 * y * y; }

int main() {
    const int MAX = 5000;
    for (std::string nombre : {"SGD", "momentum", "Adam"}) {
        double x = 5, y = 5, vx = 0, vy = 0, mx = 0, my = 0, sx = 0, sy = 0;
        int paso = 0;
        for (; paso < MAX && f(x, y) > 1e-8; ++paso) {
            double gx, gy;
            gradiente(x, y, gx, gy);
            if (nombre == "SGD") { x -= 0.09 * gx; y -= 0.09 * gy; }
            else if (nombre == "momentum") { vx = 0.9 * vx + gx; vy = 0.9 * vy + gy; x -= 0.01 * vx; y -= 0.01 * vy; }
            else {                                          // Adam
                double b1 = 0.9, b2 = 0.999, e = 1e-8, lr = 0.3, t = paso + 1;
                mx = b1 * mx + (1 - b1) * gx; my = b1 * my + (1 - b1) * gy;
                sx = b2 * sx + (1 - b2) * gx * gx; sy = b2 * sy + (1 - b2) * gy * gy;
                x -= lr * (mx / (1 - std::pow(b1, t))) / (std::sqrt(sx / (1 - std::pow(b2, t))) + e);
                y -= lr * (my / (1 - std::pow(b1, t))) / (std::sqrt(sy / (1 - std::pow(b2, t))) + e);
            }
        }
        std::cout << nombre << ":  " << paso << " pasos,  f final = " << f(x, y) << "\n";
    }
}

momentum:  201 pasos,  f final = 1.44355e-09

3.7 Entrenar bien: inicialización, regularización y diagnóstico

Una red que "no entrena" casi siempre es uno de pocos problemas conocidos. Conviene tenerlos a mano:

  • Gradientes que se desvanecen: con sigmoide, la derivada máxima es 0.25, y en saturación es casi 0 (con \(z=10\) vale \(\approx 4.5\times10^{-5}\)). En una red profunda, multiplicar muchas derivadas chicas deja un gradiente nulo en las primeras capas. ReLU y una buena inicialización lo mitigan. Lo opuesto, que explotan, se ve como una pérdida que se vuelve nan.
  • Inicialización: los pesos iniciales se escalan según el tamaño de la capa para que la varianza de las activaciones se mantenga entre capas (Xavier para tanh/sigmoide, He para ReLU).
  • Weight decay: sumar \(\lambda\|w\|^2\) a la pérdida. Es el ridge de 2.3 aplicado a los pesos de la red.
  • Dropout: durante el entrenamiento, apagar al azar una fracción de las neuronas en cada paso (y reescalar). Obliga a que ninguna neurona sea imprescindible.
  • Normalización por lotes (batch norm): normalizar las activaciones de cada capa con la media y el desvío del lote; estabiliza y acelera.
  • Parada temprana (early stopping): dejar de entrenar cuando la pérdida de validación deja de bajar.

3.8 Convoluciones y redes convolucionales (CNN)

Para imágenes, una capa densa tiene un problema: una imagen de 28×28 con 100 neuronas ocultas son 78.400 pesos, y encima ignora que un píxel está al lado de otro. Una convolución desliza un filtro chico (por ejemplo 3×3) por toda la imagen, usando los mismos pesos en cada posición: menos parámetros y detecta un patrón (un borde, una esquina) sin importar dónde aparezca.

conv2d.cppc++
#include <iostream>
#include <vector>
#include <iomanip>

using Img = std::vector<std::vector<double>>;

// convolucion "valida" (sin relleno): la salida es mas chica que la entrada
Img convolucion(const Img& in, const Img& k) {
    int H = in.size(), W = in[0].size(), kh = k.size(), kw = k[0].size();
    Img out(H - kh + 1, std::vector<double>(W - kw + 1, 0.0));
    for (int i = 0; i + kh <= H; ++i)
        for (int j = 0; j + kw <= W; ++j)
            for (int a = 0; a < kh; ++a)
                for (int b = 0; b < kw; ++b)
                    out[i][j] += in[i + a][j + b] * k[a][b];
    return out;
}

int main() {
    Img img(6, std::vector<double>(6, 0.0));                // izquierda oscura (0), derecha clara (9)
    for (auto& fila : img) for (int j = 3; j < 6; ++j) fila[j] = 9;
    Img sobelX = {{-1, 0, 1}, {-2, 0, 2}, {-1, 0, 1}};      // detecta bordes verticales

    Img r = convolucion(img, sobelX);
    for (auto& fila : r) { for (double v : fila) std::cout << std::setw(4) << v; std::cout << "\n"; }
}
Salida real
   0  36  36   0
   0  36  36   0
   0  36  36   0
   0  36  36   0

La imagen de 6×6 tiene la mitad izquierda oscura (0) y la derecha clara (9). El filtro es el Sobel vertical, que detecta bordes verticales. La salida (4×4, porque la ventana de 3×3 no sale de la imagen: \(6-3+1 = 4\)) vale 36 justo en las dos columnas centrales, donde la ventana abarca el borde, y 0 donde la imagen es uniforme.

  • En una CNN el filtro no se elige: se aprende por backpropagation, igual que cualquier otro peso.
  • Parámetros: el filtro 3×3 tiene 9 pesos. Una capa densa de 36 entradas (6×6) a 16 salidas tiene 576.
  • Pooling: reducir la resolución quedándose con el máximo (o el promedio) de cada bloque de 2×2. Padding y stride controlan el tamaño de salida.
  • Se apilan convoluciones: las primeras detectan bordes, las siguientes combinaciones de bordes (formas), las últimas objetos.

3.9 Secuencias: redes recurrentes (RNN, LSTM) — panorama

Para series de tiempo, texto o señales, el orden importa. Una red recurrente mantiene un estado oculto \(h_t\) que resume lo visto hasta ahora: \(h_t = \tanh(W h_{t-1} + U x_t + b)\), con los mismos \(W, U\) en cada paso. Desplegada en el tiempo, una RNN que procesa 100 pasos es una red de 100 capas que comparte pesos, y se entrena con backpropagation a través del tiempo.

Por eso sufre el desvanecimiento de gradientes de 3.7: el gradiente atraviesa 100 multiplicaciones. LSTM y GRU agregan "compuertas" que deciden qué recordar y qué olvidar, y permiten memoria larga. Para lenguaje fueron reemplazadas por los transformers (3.10), pero siguen apareciendo en series de tiempo chicas, como las de sensores (5.4, 5.5).

3.10 Atención y transformers — panorama

Los modelos de lenguaje actuales, incluidos los que traducen, resumen y conversan, son transformers. Su idea central es la atención: para cada elemento de la secuencia, mirar todos los demás y decidir con qué peso mezclarlos. Cada elemento produce tres vectores: una consulta \(Q\), una clave \(K\) y un valor \(V\), y la salida es \(\text{softmax}(QK^T/\sqrt{d})\,V\).

atencion.cppc++
#include <iostream>
#include <vector>
#include <cmath>
#include <iomanip>

using M = std::vector<std::vector<double>>;

int main() {
    // 3 palabras, cada una un vector de 2 numeros (ya proyectado a Q, K, V)
    M Q = {{1, 0}, {0, 1}, {1, 1}};
    M K = {{1, 0}, {0, 1}, {1, 1}};
    M V = {{1, 2}, {3, 4}, {5, 6}};
    int n = 3, d = 2;

    M pesos(n, std::vector<double>(n));
    for (int i = 0; i < n; ++i) {
        double suma = 0;
        for (int j = 0; j < n; ++j) {                       // puntaje = Q_i . K_j / sqrt(d)
            double s = 0;
            for (int t = 0; t < d; ++t) s += Q[i][t] * K[j][t];
            pesos[i][j] = std::exp(s / std::sqrt((double)d));
            suma += pesos[i][j];
        }
        for (int j = 0; j < n; ++j) pesos[i][j] /= suma;    // softmax por fila
    }
    std::cout << std::fixed << std::setprecision(3) << "pesos de atencion:\n";
    for (auto& f : pesos) { for (double w : f) std::cout << std::setw(7) << w; std::cout << "\n"; }
    std::cout << "salida = pesos * V:\n";
    for (int i = 0; i < n; ++i) {
        for (int t = 0; t < d; ++t) {
            double s = 0;
            for (int j = 0; j < n; ++j) s += pesos[i][j] * V[j][t];
            std::cout << std::setw(7) << s;
        }
        std::cout << "\n";
    }
}
Salida real
pesos de atencion:
  0.401  0.198  0.401
  0.198  0.401  0.401
  0.248  0.248  0.503
salida = pesos * V:
  3.000  4.000
  3.407  4.407
  3.510  4.510
  • Cada fila de "pesos de atención" suma 1: es cuánta atención le presta ese elemento a cada uno de los tres.
  • El tercer elemento, \((1,1)\), tiene mayor producto punto con su propia clave (2) que con las otras (1 y 1), y por eso se atiende a sí mismo con 0.503; su salida es una mezcla de los tres valores, ponderada por esos pesos.
  • Se divide por \(\sqrt d\) porque los productos punto crecen con la dimensión \(d\) y empujarían el softmax a saturarse (casi todo el peso en un solo elemento, gradientes nulos).
  • Costo: compara todos contra todos, \(O(n^2 d)\) en el largo de la secuencia. Es el cuello de botella de los modelos de contexto largo.

Un bloque de transformer agrega varias "cabezas" de atención en paralelo, una red densa (MLP), conexiones residuales (sumar la entrada a la salida) y normalización. Un modelo de lenguaje es una pila de estos bloques entrenada para predecir la siguiente palabra (o símbolo). El curso de Karpathy construye uno chico paso a paso.

3.11 Autoencoders y modelos generativos — panorama

Un autoencoder es una red que aprende a comprimir y a reconstruir: una parte (el codificador) lleva la entrada a un vector chico, y la otra (el decodificador) intenta reconstruir la entrada original a partir de él. Si la reconstrucción es buena, ese vector chico capturó lo esencial. Con capas lineales y una pérdida cuadrática, es exactamente PCA (2.11); con no linealidades, es un PCA no lineal.

Los modelos generativos van un paso más allá: no solo comprimen, inventan datos nuevos parecidos a los de entrenamiento. Las familias principales son los autoencoders variacionales (VAE), las redes antagónicas (GAN) y los modelos de difusión. Con autoencoders también se detectan anomalías: si una máquina falla, su señal se reconstruye mal, y esa diferencia se usa como alarma (5.4).

3.12 Aprendizaje por refuerzo — panorama

Un agente actúa en un entorno; cada acción cambia el estado y puede dar una recompensa. El agente no tiene "respuestas correctas" sino que debe descubrir qué política maximiza la recompensa acumulada. Es el marco natural del control de robots y de los juegos.

El algoritmo más simple es Q-learning: guardar una tabla \(Q(s,a)\) con el valor esperado de hacer la acción \(a\) en el estado \(s\) y actualizarla con \(Q(s,a) \leftarrow Q(s,a) + \alpha\,[\,r + \gamma \max_{a'} Q(s',a') - Q(s,a)\,]\). El factor \(\gamma<1\) descuenta el futuro. Hay que equilibrar explorar (probar acciones nuevas, política \(\varepsilon\)-codiciosa) y explotar (usar lo que ya sabe).
